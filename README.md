## 👨‍💻 About Me

I'm a **PCB Design Engineer** (B.E. ECE, 2025) who turns schematics into manufacturable boards. My day-to-day is **ATE loadboard design**, where signal quality, tight tolerances and clean documentation decide whether a board ships or comes back.

- 🔌 Specialising in **ATE loadboard** schematic capture and layout
- 🎯 Focused on **signal integrity, power integrity and DFM-aware layout**
- 🧰 Daily drivers: **Cadence Allegro PCB Designer** and **OrCAD Capture**
- 🔁 Also fluent in **Altium Designer** and **KiCad**
- 💻 I can also write software (Python, Java, web), which helps with test scripts, automation and tooling
- 💼 Founder of **Dev2Designs**, my freelance design studio
- 🗣️ English & Tamil

## ⚡ What I Do

| Stage | Focus |
|---|---|
| 📐 **Schematic Design** | Component selection, library creation, OrCAD Capture hierarchy, BOM |
| 🧩 **PCB Layout** | Stackup planning, placement, constraint-driven routing in Allegro |
| 📡 **Signal & Power Integrity** | Impedance control, length matching, return paths, decoupling strategy |
| 🧪 **ATE Loadboards** | Tester-to-DUT interface boards, socket and connector fan-out |
| 🏭 **Fabrication Output** | Gerbers, drill files, assembly drawings, DFM / DFA checks |
